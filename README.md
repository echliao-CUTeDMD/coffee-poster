# 深坑・山水共學

以深坑老街、景美溪及南側聚落為範圍的中國科技大學 USR 互動展示。

## 使用
以現代瀏覽器開啟 index.html。單一 HTML 包含資料、樣式與模型程式；首次載入需網路以取得 jsDelivr 上的 Three.js 0.160.0。若瀏覽器限制本機模組載入，可在此資料夾執行 `python -m http.server 8771 --bind 127.0.0.1`，開啟 http://127.0.0.1:8771。

拖曳旋轉、滾輪或雙指縮放；點選地點／清單查看內容。可使用六站導覽、搜尋、四個USR主軸、六條共學動線、早晚情境、人物與標籤切換、暫停及鳥瞰。手機詳情抽屜可展開或拖曳。方向鍵旋轉，Escape 關閉詳情。
