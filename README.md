# BREW STUDIO 咖啡海報工作室

繁體中文咖啡海報產生器。純 HTML / CSS / JavaScript，無須安裝套件、API 金鑰或後端服務。照片只在瀏覽器記憶體內處理。

## 功能

- 70 款模板：簡易風格、新聞台報導、台灣景點手繪、復古電影、日式動漫遊戲、Henry 咖啡職人各 10 款，加上原創咖啡版型 10 款。
- 分類選單、完整底圖縮圖；新風格可調整照片區塊大小、上下位置與文字上下位置。
- 新風格底圖以完整顯示方式適配三種比例，必要時保留外側留邊，不裁掉原圖字幕或裝飾。
- 上傳自訂底圖及調整遮罩。
- 最多 12 張 JPG / PNG / WebP 照片，單張上限 20 MB。
- 自動拼貼、照片排序、刪除、縮放和水平／垂直裁切位置。
- 編輯品牌、標題、副標題、頁尾、字體、文字顏色和大小。
- 1080 × 1350、1080 × 1080、1080 × 1920 三種尺寸。
- PNG / JPG 高畫質下載，無浮水印。
- 不需外部字體、圖片 CDN 或追蹤服務。原創咖啡插畫由 Canvas 繪製；新增底圖來自使用者提供的 60 張圖片。

這是圖片排版合成工具，不包含生成式 AI。預覽與輸出使用相同 Canvas。上傳圖片會等比例縮小至最長邊 2400 px，以減少記憶體使用。重新整理會清除編輯內容，請先下載。超長文字會自動縮小，標題最多顯示四行。

## 本機使用

直接以瀏覽器開啟 `index.html` 即可。也可以在此資料夾執行：

```sh
python -m http.server 8080
```

開啟 http://localhost:8080 。

## 上傳 GitHub 與發佈 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `coffee-poster`。
2. 將本資料夾的 **內容** 上傳至 repository 根目錄。必須包含 `index.html`、`style.css`、`app.js`、`style-templates.js`、`templates-data.js`、`.nojekyll`；README 可一併上傳。
3. 進入 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選 **Deploy from a branch**。
5. 選擇 `main` 分支及 `/ (root)`，按下 Save。
6. 部署完成後，由 Pages 頁面開啟網站網址，通常是 `https://你的帳號.github.io/coffee-poster/`。

只需上傳此資料夾，無須上傳上層的研究文件或影片。所有資源使用相對路徑，可部署在 GitHub Pages 的子路徑下。

## 驗收建議

切換七個分類及 70 款模板；上傳 1 / 2 / 12 張圖片並排序、刪除、裁切；套用及移除底圖；修改文字；切換三種比例；分別下載 PNG 和 JPG。手機版編輯面板在上、預覽在下。瀏覽器需支援 Canvas roundRect（現代 Chrome、Edge、Firefox、Safari）。

## 風格素材與編輯行為

`templates-data.js` 內含 60 張原尺寸 1122 × 1402 的 WebP 底圖及小尺寸縮圖，圖片採品質 88 壓縮。圖片以資料網址打包，因此直接開啟本機 HTML 仍可合成下載，不需依賴 Downloads 資料夾。請將此檔一併上傳。

選擇分類只篩選模板清單；點擊縮圖才套用模板。套用模板會保留照片與文字，移除自訂底圖，並重設文字顏色及區塊位置以符合新模板。新聞模板上的既有文字屬於底圖本身，無法在文字面板修改；面板編輯的是新增文字。可取消「顯示海報文字」來隱藏新增文字。

## 本次驗證

已通過 JavaScript 語法檢查；使用原生 Canvas 執行 70 模板 × 3 比例 × 0 / 1 / 12 照片，共 630 次合成，另驗證分類切換、自訂底圖、文字顯示切換與 PNG / JPEG 編碼，並檢視原有五種風格及全部 10 款 Henry 風格的合成樣張。這些是程式與繪圖驗證；瀏覽器安全政策禁止工具讀取本機 file:// 網頁，因此未完成瀏覽器點擊及下載端到端測試。

### Henry 咖啡職人

新增獨立分類，共 10 款。依每張底圖的人物位置設定照片預設區塊，新增文字集中在上方留白。可在「照片」調整照片區塊大小、上下位置，在「文字」調整文字位置或關閉新增文字。人物與底圖上的 HENRY 字樣屬於原圖，不能獨立移動。
